# Writing the Paper

Think of the paper as a children's story.

Each page should include a figure and text explaining it.

## Think About the Narrative

1. We aim to classify suspicious users based on their network behavior.

2. IO Drivers exhibit behavioral similarities, such as coordinated actions and entity reuse.

3. Current classifiers models are black box.

4. Most IO drivers are embedded in dense similarity-behavior-graph regions, motivating graph indicators such as `core_number`.

5. Use a clear graph layout that reveals the network structure and groups users into rings, with IO drivers concentrated in the inner ring.

6. Examine whether additional graph indicators can identify suspicious users beyond `core_number`, particularly indicators related to IO network structure.

7. Present the classification results.

8. Compare different system configurations.

9. Write about temporal analysis **or** successful IO drive classification using `TF-IDF`.
